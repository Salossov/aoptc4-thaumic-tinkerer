# Thaumic Tinkerer

[Русский](README.ru.md)

I am porting Thaumic Tinkerer 2.5-1.7.10-164 to Minecraft 1.21.1 / NeoForge through the public AOP: Thaumcraft 4 API. Development is in progress.

Build against a compatible Thaumcraft API JAR. Optional dependencies can be supplied explicitly through Gradle properties or placed in `libs/`.

## Building

JDK 21. Dependency versions are defined in `gradle.properties`.

```powershell
./gradlew.ps1 assemble
```
