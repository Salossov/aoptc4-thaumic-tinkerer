# Thaumic Tinkerer

[English](README.md)

Я переношу Thaumic Tinkerer 2.5-1.7.10-164 на Minecraft 1.21.1 / NeoForge через публичный API AOP: Thaumcraft 4. Порт находится в разработке.

Build against a compatible Thaumcraft API JAR. Optional dependencies can be supplied explicitly through Gradle properties or placed in `libs/`.

## Сборка

JDK 21. Версии зависимостей заданы в `gradle.properties`.

```powershell
./gradlew.ps1 assemble
```
