# Thaumic Tinkerer: правила переноса

- Назначение этой папки: порт аддона на Minecraft 1.21.1 для существующего Thaumcraft в основном `repo` проекта.
- Эталон: Thaumic Tinkerer 2.5-1.7.10-164, SHA-1 `e50a70d3f65bdfb59c2fef2db2d6515aa1e640f1`.
- Декомпиляция, исходный JAR, кэши и инструментальные отчёты остаются вне этой папки. Не добавляй их в историю или игровой JAR.
- Сохраняй исходные значения, порядок регистрации и наблюдаемое поведение. Изменения механик и вынужденные отклонения сначала согласуй с пользователем и зафиксируй согласованное решение.
- Сохраняй авторство оригинала и условия CC BY-NC-SA 3.0, указанные в README исходников. Разрешения на публикацию Thaumcraft не следуют из лицензии Tinkerer.
- Принятые решения пользователя (2026-10-18): постоянный mod ID/namespace — `thaumictinkerer`; аддон использует только публичный API Thaumcraft. Недостающие контракты разрешено добавлять в API и реализацию ядра по потребностям переноса. Эти решения повторно не согласовывай. Перед другими неоговорёнными продуктовыми/архитектурными решениями спроси пользователя.
- Код оригинала можно копировать и адаптировать; пользователь явно разрешил это. Сохраняй авторство и поведение эталона, переписывай платформенные участки по необходимости.
- Используй PowerShell, не запускай CMD.exe или .bat без разрешения. Не создавай коммиты, worktree или публикации без запроса. Не используй субагентов без запроса.
- Ограничивай поиск нужным каталогом. Не запускай глобальные сканирования всего проекта без подтверждения.
- Отдельно указывай: реализация, компиляция, автоматические проверки, проверка в настоящем клиенте. Существование класса или успешная декомпиляция не доказывают работоспособность порта.
- Журналы согласований и инструментальные отчёты не включай в Git.
- Активная цель пользователя: перенести ВСЁ содержимое сборки 164, затем полностью сравнить с оригиналом и передать пользователю для личной подробной приёмки. Не останавливаться после отдельных механик. Субагенты запрещены прямым запросом пользователя. Частичная реализация не завершает цель.
